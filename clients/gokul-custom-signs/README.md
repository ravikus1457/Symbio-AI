# Gokul Custom Signs — Sample Site & Pitch

A pitch package for **Gokul Custom Signs / Gokul Printing Press & Sign
Service** (5504 Florin Rd, Sacramento, CA 95823), built by **Symbio AI**.
The prospect currently has **no website** — only third-party directory
listings — which is the core of the pitch.

```
gokul-custom-signs/
├── index.html   ← self-contained one-page sample site (no build step,
│                   no external assets — open directly in a browser)
├── PITCH.md     ← the sales pitch: problems found, benefits, upsells
└── README.md    ← this file
```

## What's on the sample site

1. **Utility bar** — address, tap-to-call phone, live **Open now / Closed**
   badge computed from the shop's real hours (Pacific time).
2. **Hero** — sign-poster lettering ("Your business, in big letters."),
   free-quote and call CTAs.
3. **Services** — signs & banners, t-shirts, business cards & flyers,
   wedding/invitation cards, invoice/receipt/order books, copies·fax·notary.
4. **Why Gokul** — owner-direct, one roof, neighborhood shop, small jobs
   welcome.
5. **Wedding & invitation cards** — dedicated feature section (bilingual
   printing, engagement/birthday/puja invitations).
6. **Free quote form** — demo submit; production would wire to email/SMS.
7. **Visit** — address, map link, hours table with today's row highlighted.

## Design

Grounded in the sign trade itself: ink navy `#14243d`, signal red
`#c4361c`, marigold `#efa02c` (hi-vis sign yellow that doubles as a nod to
the wedding-card side of the business), print-stock white `#f6f4ee`.
Display type is the heavy condensed poster stack (Impact /
Haettenschweiler) with layered vinyl-style offset shadows; body is a clean
system grotesque. Dual light/dark theme via CSS tokens.

## Source of business details

Address, phone, hours, and the services list were pulled from public
directory listings (Yelp, Chamber of Commerce, Nextdoor) in July 2026.
**Verify with the owner before presenting** — see the note at the top of
`PITCH.md`.
